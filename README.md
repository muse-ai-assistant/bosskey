# ⌨️ 老板键 · BossKey

终极摸鱼神器。一键把屏幕伪装成加班现场，老板路过也看不出破绽。

**在线体验 → https://muse-ai-assistant.github.io/bosskey/**

## 玩法

1. 选一套"工作服"：Excel 报表 / 工作群聊 / 代码编辑器
2. 点"开始摸鱼"，全屏进入伪装界面
3. 老板靠近：按 <kbd>~</kbd> 键（ESC 下面那个）或点右下角小圆点，秒切回伪装

## 伪装

- 📊 **Excel 报表**：「2026年Q3销售数据汇总.xlsx」，31 行假销售数据、公式栏、Sheet 标签，标题栏都给你改好了
- 💬 **工作群聊**：「奋斗者联盟（工作群）」，假同事轮番发言"收到""周五前发我"，敬业人设立住
- 💻 **代码编辑器**：VS Code 同款深色编辑器，带中文注释的"屎山代码"，状态栏 Python 3.11

## 技术

纯 HTML + CSS + JS，零依赖。伪装界面标题栏（document.title）同步伪装，浏览器标签页都看不出破绽。
